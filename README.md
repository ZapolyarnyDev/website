# [zapolyarnydev.ru](https://zapolyarnydev.ru)

My personal website.

## Stack

Astro, TypeScript, MDX, CSS, and pnpm.

## Development

Run `pnpm install`, then `pnpm dev`. The cat can supervise.

Run `pnpm test` to check that language switching still works.
To start a draft in `content/log/`, run `pnpm new note "Title"`.
